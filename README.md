# Sundial

<img src="docs/icon.png" width="96" align="right" />

A clean calendar app for Android. It reads and writes the calendars already on your phone
(Google, Outlook, Samsung and so on), so everything stays in sync with your accounts.

- Month view with coloured event pills; swipe to change month, long-press a day to add an event
- Upcoming list for the next four months
- Add, edit and delete events: all-day, repeats, reminders, location, notes
- Delete just one repeat or the whole series
- Show or hide each calendar, choose the week start, default calendar and reminder
- Light and dark mode follow the system
- Opens "add to calendar" links and event links from other apps

Kotlin, no third-party libraries. Android 12 or newer.

## Download

Every push to `main` builds a new APK:
**[Sundial.apk](https://github.com/wellsey001/Sundial/releases/latest/download/Sundial.apk)**

Each build is signed with the same key, so new versions install over the old one.
